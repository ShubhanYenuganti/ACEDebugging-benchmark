## 1. Abstract

ACE-Bench is a framework for measuring the correctness of AI-generated AWS Infrastructure as Code against a ground truth corpus derived from the AWS Reference Architecture library. It addresses two compounding gaps in existing IaC evaluation approaches: that structural validity and successful deployment are necessary but insufficient signals of correctness, and that correctness cannot be evaluated against a single reference solution when the prompt is intentionally ambiguous enough to admit multiple valid architectures.

A CloudFormation template can pass a linter, reach CREATE_COMPLETE, and still be semantically wrong — misconfigured resource bindings, logically broken conditions, incomplete route tables, or IAM grants that silently fail at runtime. It can also be functionally correct while violating the architectural best practices that make it production-grade. ACE-Bench evaluates agent output across three ordered correctness gates — Build, Semantic, and Functional — and applies a fourth scoring dimension for Well-Architected alignment and implicit professional requirements expressed as a penalty rather than a gate.

The corpus is derived from approximately 358 AWS reference architecture diagrams, each carrying explicit traffic flow descriptions, service role definitions, and documented architectural decisions with rationale. Prompts are distilled from these sources but augmented to require combining or extending the reference pattern, and calibrated so that multiple valid AWS implementations exist for each prompt. Ground truth is therefore defined not as a single correct template but as a set of WAF-grounded correctness criteria that any valid implementation must satisfy.

All deployment and functional testing executes against LocalStack, a local cloud emulation platform that implements the same AWS service APIs used throughout the pipeline. This eliminates live AWS account dependencies, enables parallel evaluation across many tasks, and allows each evaluation run to operate against a clean, isolated, disposable environment.
